# A-DLCC

This repository provides the Python code for **Automatic Depth-based Local Center Clustering (A-DLCC)** via β-integrated local depth and adaptive grouping.

> **Note:**
> The Python code was written with Cursor, so with AI assistance.

## Structure
* `adlcc/`: Core functions for A-DLCC
* `experiments/`: Scripts for the paper experiments and figures
* `data/`: Data files used by the experiments

## Datasets
Some are included in the repository (`data/`); Iris, Wine and BC come from scikit-learn. Other datasets used in the paper can be found at:
[https://github.com/lytgysrn/dlcc](https://github.com/lytgysrn/dlcc)

## Usage

```
pip install -r requirements.txt
python experiments/run_paper.py
```
